# 🌸 Flower Classification Using CNN

## 📌 About the Project
This project uses a **Convolutional Neural Network (CNN)**, a Deep Learning algorithm, to classify flower images into different categories.

The CNN model automatically learns features such as colours, shapes, petals, and textures to identify different types of flowers.

## 🎯 Objectives
- To develop a flower classification model using CNN.
- To identify different types of flowers from images.
- To extract image features automatically.
- To achieve accurate flower classification using Deep Learning.

## 🌺 Flower Categories
The model can classify flowers into five categories:

1. Daisy
2. Dandelion
3. Rose


## ⚙️ How CNN Works

1. **Input Layer:** Takes flower images as input.
2. **Convolution Layer:** Extracts features such as petals, shapes, and colours.
3. **ReLU Layer:** Applies an activation function.
4. **Pooling Layer:** Reduces the image feature dimensions.
5. **Flatten Layer:** Converts feature maps into a one-dimensional array.
6. **Fully Connected Layer:** Performs flower classification.
7. **Output Layer:** Predicts the flower category.
